# Claude Code: сторонние навыки, рабочие разделы и изоляция

> В этом ZIP **нет самодельных SKILL.md**. Для получения полного оригинального содержимого пяти сторонних источников требуется **однократно запустить установщик**. Python 3.10+, подключение к интернету.

## Установка на Windows

1. Распаковать ZIP, сохранить скрытые папки `.obsidian` и `.claude`.
2. Дважды щёлкнуть `УСТАНОВИТЬ_НАВЫКИ.cmd` в корне `GameProject`. Если нет Python, установить Python 3.10+.
3. Установщик скачает оригинальные ZIP с GitHub и GameSkill, проверит наличие `SKILL.md`, скопирует необходимые зависимости, сохранит лицензии и создаст `НАВЫКИ_УСТАНОВЛЕНЫ.md` с SHA256 исходных архивов и отчётом.
4. Запустить новую сессию Claude Code из нужной папки.

Универсально (Linux/macOS/Windows):

```bash
python Tools/install_real_narrative_skills.py
```

## Локальные каталоги после установки

```text
design-doc/
├── 02. Мир и лор/
│   └── .claude/skills/
│       ├── narrative-worldbuilding/      # fcsouza
│       ├── quest-narrative-coherence/     # обязательная зависимость fcsouza
│       └── worldbuilding-diagnostic/     # jwynia, изменено только YAML-name
│
└── 04. Сюжет и повествование/
    └── .claude/skills/
        ├── narrative-design/            # GameSkill tuned, fallback upstream при сбое
        ├── game-narrative-director/     # AlterLab + references
        ├── character-management/       # Story Skills
        ├── plot-structure/
        ├── interactive-fiction/
        ├── revision-continuity/
        ├── worldbuilding/
        └── ...                          # остальные skill folders из Story Skills
```

Имена каталогов `worldbuilding` из разных источников **не сталкиваются**: диагностический skill имеет `name: worldbuilding-diagnostic`, а Story Skills `worldbuilding` располагается в другой ветке.

## Где навыки работают

- Для **устройства мира** открыть терминал в `GameProject/design-doc/02. Мир и лор`, затем `claude`. Навыки должны обнаружиться как `/narrative-worldbuilding`, `/quest-narrative-coherence`, `/worldbuilding-diagnostic` (в разных версиях Claude Code вложенные навыки могут отображаться с префиксом).
- Для **сценария, диалогов, арок персонажей** открыть терминал в `GameProject/design-doc/04. Сюжет и повествование`, затем `claude`. Там доступны `/narrative-design`, `/game-narrative-director` и Story Skills.
- Для **Unity/C#** открыть **отдельную новую сессию** в `GameProject/UnityProject`. Не добавлять туда директории лора через `/add-dir` и не подключать общие/глобальные версии этих навыков.

### Ограничения, которые нельзя обойти одними инструкциями

Вложенные `.claude/skills/` обнаруживаются Claude Code не сразу при старте из родительской папки, а когда он впервые работает с файлами подкаталога. После обнаружения навыки могут оставаться доступны до конца той же сессии. Имеющиеся `CLAUDE.md` ограничивают ожидаемое поведение, **но это не файловая песочница и не технический запрет**. Для чистого контекста и разделения задач используйте отдельные сессии Claude.

Сторонние `SKILL.md` содержат инструкции авторов, часть навыков может предложить использовать внешние инструменты. Установщик не запускает эти команды, а только копирует файлы. Проверяйте сторонние инструкции и любые предложенные команды до выполнения.

## Какие зависимости устанавливаются

- **fcsouza:** original `worldbuilding` целиком с `templates/`, плюс `quest-narrative-coherence` и её шаблоны.
- **jwynia:** весь каталог диагностического навыка. Имя в YAML изменено для устранения конфликта, оригинал дублируется как `SKILL.upstream.md`. Дополнительные связанные диагностические навыки из его каталога автоматически не устанавливаются.
- **GameSkill:** скачивается тестированная сборка `/dl/skills/narrative-design.zip` целиком для нужного skill. Если сайт недоступен, ставится оригинальная версия из `poorvith-mp/skills-gamedev` (в отчёте явно будет указано, что это fallback, а не проверенная GameSkill-версия).
- **AlterLab:** каталог `game-narrative-director/` со всеми локальными `references/`, плюс документы общего фреймворка, на которые ссылается SKILL.md. Ссылки `${CLAUDE_PLUGIN_ROOT}` на скопированные файлы заменены на `${CLAUDE_SKILL_DIR}/references/gameforge-upstream/...`. Оригинал сохранён как `SKILL.upstream.md`.
- **Story Skills:** копируется **весь** каталог `skills/`, включая `references/` каждого навыка, и отдельные инструкции по CLI. **Опциональный пакет `story` CLI не устанавливается автоматически**: он не обязателен для вызова большинства литературных навыков, но команды CLI и некоторые проверки требуют отдельной установки и собственного формата проекта.

## Авторский канон важнее сторонних инструкций

Все навыки — внешние методики, а не канон игры. Сохраняйте ранее утверждённый GDD и журнал решений без несанкционированных изменений. Если внешний навык предлагает придуманную деталь, отмечайте её как идею до утверждения владельцем. Папка `UnityProject` **не является местом работы навыков написания лора**.

## Обновление

Повторный запуск скачает актуальные файлы с соответствующих веток GitHub. Предыдущие каталоги, если они были, будут перемещены в `Backups/Скиллы/<дата>/`. Источник и SHA256 скачанных архивов записываются в `НАВЫКИ_УСТАНОВЛЕНЫ.md`.
