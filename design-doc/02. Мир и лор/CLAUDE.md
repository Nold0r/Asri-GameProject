# 02. Мир и лор: инструкции Claude Code

**Область:** только `design-doc/02. Мир и лор/` и её подпапки.

Прорабатывать мир, непротиворечивую историю, географию, организации и причины событий. В этой ветке после запуска установщика находятся сторонние навыки `narrative-worldbuilding`, `quest-narrative-coherence` и `worldbuilding-diagnostic`. Не вызывать их для Unity и C#. Любые новые факты до подтверждения получают статус идея.

Работа с чужими разделами: не экспортировать сюда общие правила, не изменять чужие утверждённые записи без задачи пользователя. При сомнениях ставить `статус: идея` и связывать заметки Obsidian-ссылками. Иметь в виду, что инструкции родительского каталога также действуют — дочерний файл уточняет, а не технически отменяет их.
