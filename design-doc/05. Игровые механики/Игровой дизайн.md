# Служебные системы

## Сохранения

Правила и области сохраняемых данных описаны в [[Правила сохранений]].

- Игра автоматически сохраняет забег после каждой пройденной комнаты.
- После аварийного завершения игры забег восстанавливается с последней пройденной комнаты.
- Обычный выход с возможностью продолжить позже разрешён только в специальных комнатах или между этажами.
- В разрешённой точке игрок также может завершить забег и вынести добычу.
- Совместная сессия хранится у хоста; его отключение разрывает соединение для всех участников.

## Управление

Физические клавиши и поддерживаемые устройства пока не выбраны.

| Действие | Согласованное поведение |
| --- | --- |
| Короткое нажатие атаки | Один базовый удар; повторные нажатия продолжают серию |
| Удержание атаки | Тяжёлая атака |
| Рывок | Использует одно из двух общих для отряда применений |
| Обычный навык | Применяет доступную способность героя |
| Ультимейт | Применяет ультимейт; может менять стойку и способности |
| Смена героя | Переключает на другого доступного героя |
| Смена цели | Меняет врага в автофокусе |

Действия перемещения, прыжка и управления камерой ещё нужно описать подробнее.

## Интерфейс

Игрок должен видеть, какой враг находится в автофокусе. Конкретный вид индикатора, состав HUD, меню и настройки пока не определены.

## Сетевая игра

### Режимы

Совместный забег работает по сети через LAN или Steam API. Конкретные сетевые библиотеки и способ выбора подключения ещё не определены.

### Распределение отряда

В совместном забеге есть четыре слота. Подключившиеся игроки приходят со своими персонажами и занимают часть этих слотов.

| Игроков | Распределение слотов | Переключение |
| --- | --- | --- |
| 1 | До четырёх у одного игрока | Между своими героями |
| 2 | По два у каждого | Между двумя своими героями |
| 3 | Два у хоста, по одному у остальных | У хоста между двумя героями |
| 4 | По одному у каждого | Недоступно |

### Отключение участника

Если отключился участник, который не является хостом, забег продолжается.

| Состав до отключения | Кому переходят герои |
| --- | --- |
| Два игрока | Два героя отключившегося участника переходят хосту |
| Три игрока | Герой переходит участнику с меньшим числом героев; получается распределение по два |
| Четыре игрока | Герой переходит хосту |

Отключившийся участник попадает в лобби и может вернуться до конца текущего этажа. При повторном подключении он автоматически получает обратно своих прежних героев.

Его реликвии и их эффекты убираются вместе с ним. Герои передаются другим участникам без реликвий отключившегося игрока. Применяются ли к этим героям реликвии нового управляющего — нужно уточнить.

### Отключение хоста

- Совместная сессия существует у хоста.
- Если хост отключается, из сессии отключаются все.
- Роль хоста другому участнику не передаётся.
- Хост может восстановить забег с последней пройденной комнаты.
- После восстановления прежние участники могут вернуться в пределах этажа по тем же правилам повторного подключения.

Возможность первого подключения нового участника посреди этажа пока не определена.

# Геймплейные системы

## Персонажи и отряд

### Общая схема

Герои используют один универсальный префаб управляемого персонажа. Различия между героями задаются данными и поведением способностей.

Возможны персонажи ближнего, дальнего и магического боя, а также персонажи, играющие через призывы существ. У героев могут отличаться длина серии, анимации и тайминги ударов. Общие действия и правила воздушного боя сохраняются.

### Характеристики и ресурсы

- Характеристики, HP и энергия принадлежат отдельным героям.
- Должна оставаться возможность создавать героев с общим запасом HP.
- Полный список характеристик, правила получения энергии и поведение неактивных героев ещё не определены.

### Данные персонажей

Данные редактируются в Google Таблицах и автоматически экспортируются в проект скриптом. Описание героя включает ссылки или идентификаторы модели, анимаций, звуков, материалов и классов навыков.

Формат экспорта, расписание запуска и сопоставление строк таблиц с ресурсами Unity ещё не выбраны. См. [[Архитектура игры]].

## Боевая система

### Базовые атаки и серии

Короткое нажатие выполняет один удар. Повторные нажатия складывают удары в серию, длина и тайминги которой зависят от героя.

Серия сбрасывается:

- через 1,5 секунды после последнего удара;
- при рывке;
- при применении навыка;
- при тяжёлой атаке.

Завершение серии подбрасывает врага. Сбрасывается ли серия при смене героя, ещё нужно уточнить.

### Воздушный бой и тяжёлая атака

| Действие | Результат |
| --- | --- |
| Короткая базовая атака в воздухе | Продлевает нахождение поражённого врага в воздухе |
| Завершение серии | Подбрасывает врага |
| Тяжёлая атака на земле | По завершении подбрасывает врага |
| Тяжёлая атака в воздухе | Выполняет удар вниз и опрокидывает врага на землю |

Тяжёлая атака запускается удержанием кнопки атаки. Порог удержания, окна продолжения серии и условия успешного завершения комбо пока не заданы.

### Навыки и ультимейт

Стандартный герой имеет обычный навык и ультимейт. Система должна допускать расширение этого набора:

- добавление новых активных способностей;
- изменение обычного навыка;
- переход в другую стойку или режим через ультимейт;
- другие индивидуальные механики героя.

Общий набор не должен ограничивать разработку необычных персонажей.

### Переключение героев

В одиночном забеге отряд содержит до четырёх героев. Игрок может переключаться между ними во время боя.

При выходе нового героя может выполняться удар по противнику.

| Ограничение | Значение | Область действия |
| --- | --- | --- |
| Откат переключения | 1 секунда | Общий для переключения |
| Откат удара при входе | 5 секунд | Отдельный у каждого героя |

Если удар входящего героя ещё не восстановился, переключение происходит без удара.

### Рывок

- Доступен всем героям.
- Есть два применения; запас общий для отряда.
- Смена героя не восполняет запас.
- Применения восстанавливаются со временем.
- Завершение атакующего комбо сразу восстанавливает оба применения.

Длительность восстановления ещё не выбрана. Область общего запаса при нескольких игроках также требует уточнения.

### Автофокус

Автофокус выбирает ближайшего врага. Игрок может сменить цель кнопкой и должен видеть текущую цель.

Условия потери цели, радиус поиска и порядок переключения ещё не определены.

### Враги и расчёт боя

Типы врагов, AI, урон, сопротивления, статусы, прерывания и правила работы призванных существ ещё не описаны.

## Реликвии

### Назначение

Реликвии — экипировка, которая меняет игровой процесс. У каждой есть тип и редкость.

### Использование

| Вариант | Результат |
| --- | --- |
| Разобрать | Получить валюту |
| Пожертвовать | Вместе с валютой и другими реликвиями нужных типов открыть талант персонажа |
| Взять из лобби | Начать забег с выбранными реликвиями; максимум три |

### Получение во время забега

Найденные реликвии начинают действовать сразу. Ограничение в три относится только к стартовому набору из лобби. Общего лимита действующих реликвий внутри забега нет.

### Владение

На игрока действуют только его собственные реликвии. При отключении участника кооператива его реликвии и эффекты убираются из сессии.

Поведение реликвий при передаче управления героями описано в разделе «Сетевая игра» выше. Повторные экземпляры, сочетания эффектов и распределение находок между игроками ещё нужно описать.

### Прочность

- У реликвии три использования — на три забега.
- После успешного выхода взятая реликвия возвращается в лобби с прочностью на одно использование меньше.
- При нулевой прочности реликвия исчезает.
- При поражении взятые реликвии теряются независимо от оставшейся прочности.

Расходуется ли прочность у реликвии, найденной в текущем забеге, при первом выходе в лобби — нужно уточнить.

## Прогрессия и экономика

### Лобби

После успешного выхода у игрока остаются вынесенные валюта и реликвии. Он может использовать их для подготовки к следующему забегу и открытия талантов.

### Древо талантов

У персонажа есть древо с активными и пассивными умениями. Для открытия узла могут потребоваться валюта и несколько реликвий определённых типов. Пожертвованные реликвии расходуются.

Открытые таланты остаются у персонажа навсегда между забегами. Лимит выбранных активных умений и правила выбора талантов пока не определены.

### Расходование ресурсов

| Ресурс | Согласованное применение |
| --- | --- |
| Валюта | Открытие навыков и талантов персонажа |
| Реликвии | Разбор на валюту, пожертвование для таланта, использование в забегах |

Цены, рецепты открытия талантов и источники наград пока не заданы.

## Забег и этажи

### Обычный этаж

Обычный этаж складывается из связанных псевдооткрытых комнат. Их содержимое частично генерируется процедурно, а комнаты вместе образуют этаж.

Можно возвращаться в уже пройденные комнаты того же этажа. Способ перехода между комнатами и этажами, правила генерации и возможность возврата на предыдущий этаж ещё не определены.

### Особые этажи

Есть этажи передышки и другие специальные этажи, у которых нет структуры из комнат. Их содержание ещё нужно описать.

### Выход, добыча и поражение

| Событие | Что происходит |
| --- | --- |
| Разрешённый выход с продолжением позже | Забег откладывается |
| Добровольное завершение в разрешённой точке | Предметы и валюта выносятся в лобби |
| Поражение отряда | Забег заканчивается; всё добытое и всё взятое в забег теряется |
| Аварийное завершение игры | Восстановление с последней пройденной комнаты |

Обычный выход разрешён только в специальных комнатах или между этажами. Точный момент поражения отряда, смерть отдельных героев и возможность их восстановления ещё нужно описать.

## Комната вторжения

- Необязательная PvP-комната для двух игроков.
- Доступна только во время одиночных забегов.
- Оба участника входят добровольно.
- Каждый сражается со своим полным отрядом.
- Соперник выглядит как тень.
- Победитель получает бонусы, проигравший — дебафы.
- Ни победа, ни поражение в этой комнате не завершают основной забег.

Таким образом, поражение во вторжении имеет своё последствие и не запускает правило полной потери забега. Подбор соперника, вид наград и дебафов, их длительность и способ возврата ещё не определены.
