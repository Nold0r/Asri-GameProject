# Narrative Design: self-check / 自检清单

- [ ] 每句台词先过"真人会这么说吗" / Every line passes the real-person test
- [ ] 选择要在种类上不同，不只是程度不同 / Choices differ in kind, not degree
- [ ] 设定始终可选，关键路径不依赖收集品 / Lore is optional; critical path stands alone
- [ ] 每个主要剧情节点都连到玩法后果 / Every major beat has a gameplay consequence
- [ ] 不写"as you know"式解释对话 / No as-you-know dialogue
