# Экспорт данных — вопросы

В [[Архитектура игры]] зафиксировано использование Google Таблиц для редактирования данных героев и автоматического экспорта. Форматы и механизм не выбраны.

- [ ] Выбрать таблицы и диапазоны данных.
- [ ] Определить устойчивые идентификаторы, связи с персонажами и ассетами.
- [ ] Выбрать формат экспорта (JSON/ScriptableObject/другое).
- [ ] Определить момент обновления, валидацию и отчёт об ошибках.
- [ ] Согласовать, какие ещё типы контента редактируются через таблицы.
