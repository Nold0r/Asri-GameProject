# Структура Unity — предложение

Это **черновой ориентир**, а не утверждённая архитектура. Версия Unity, пакеты и подход к организации кода ещё не согласованы. См. [[Архитектура игры]] и [[Открытые вопросы]].

После создания проекта можно рассмотреть организацию вокруг `Core`, `Combat`, `Squad`, `Runs`, `Relics`, `Extraction`, `Multiplayer`, `UI` и `Content`; конкретная схема сборок и границ систем требует отдельного проектирования.

**Не создавать Unity-проект из этой заметки автоматически.**
