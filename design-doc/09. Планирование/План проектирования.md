# План проектирования

## О чём документ

Порядок подготовки документации и архитектуры. Сейчас работа ограничена планированием. Отметки выполнения относятся к документам, а не к готовым игровым системам.

## Описано

- [x] Основные правила атак, серий, воздушного боя и рывков.
- [x] Отряд, переключение и откаты входящих ударов.
- [x] Распределение героев в кооперативе и основные правила отключения.
- [x] Добровольная PvP-комната одиночного забега.
- [x] Общая структура этажей и особых этажей.
- [x] Правила аварийного восстановления, выхода и поражения.
- [x] Реликвии, прочность, валюта и постоянные таланты.
- [x] Google Таблицы как источник данных героев.
- [x] Перенос документации в структуру по референсу.

## Дальнейшая работа

### Уточнить требования

- [ ] Закрыть вопросы, влияющие на владение состоянием и сохранения, из [[Открытые вопросы]].
- [ ] Описать перемещение, прыжки, камеру и устройства управления.
- [ ] Описать смерть героя, поражение отряда и восстановление героев.
- [ ] Описать получение добычи и эффекты реликвий в кооперативе.
- [ ] Описать нужную глубину генерации комнат и этажей.
- [ ] Описать врагов, урон, статусы и призванных существ.
- [ ] Уточнить целевые платформы и технические ограничения.

### Спроектировать архитектуру

- [ ] Сравнить подходы к организации проекта и выбрать один.
- [ ] Определить границы и связи систем.
- [ ] Описать папки, файлы и сборки Unity.
- [ ] Описать сцены, универсальный префаб и его компоненты.
- [ ] Спроектировать данные и автоматический экспорт Google Таблиц.
- [ ] Спроектировать сеть, передачу управления и повторное подключение.

### Проверить документ

- [ ] Проверить, что все согласованные механики отражены в архитектуре.
- [ ] Проверить расширение на новых героев, способности и реликвии.
- [ ] Проверить переходы между одиночным режимом, кооперативом и вторжением.
- [ ] Проверить, что нерешённые вопросы не записаны как принятые решения.
