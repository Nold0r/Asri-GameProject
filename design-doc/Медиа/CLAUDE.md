# Медиа: инструкции Claude Code

**Область:** только `design-doc/Медиа/` и её подпапки.

Систематизировать медиа в Obsidian-хранилище, не переписывать и не переименовывать бинарники без проверки всех ссылок. Папка Вложения — стандарт для новых вставок.

Работа с чужими разделами: не экспортировать сюда общие правила, не изменять чужие утверждённые записи без задачи пользователя. При сомнениях ставить `статус: идея` и связывать заметки Obsidian-ссылками. Иметь в виду, что инструкции родительского каталога также действуют — дочерний файл уточняет, а не технически отменяет их.
