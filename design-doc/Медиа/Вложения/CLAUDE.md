# Вложения — локальные правила

Область: только эта подпапка. Место для любых новых файлов, вставленных через Obsidian; не удаляй файлы, пока ссылки не проверены.

- Не создавать канон автоматически, новые предположения помечать.
- Согласованные механики — только в [[Игровой дизайн]]; текущая заметка даёт ссылку на источник, а не повторяет его.
- Не изменять чужие разделы и Unity-код без отдельной явной задачи.
