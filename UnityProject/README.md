# Место для Unity

Сейчас здесь только правила для Claude Code. Через Unity Hub создайте **новый** проект в `UnityProject/Game/` — это ещё не существующий вложенный каталог. Родительские инструкции `UnityProject/CLAUDE.md` будут действовать в нём.

Почему не создаём пустую структуру `Assets/Packages/ProjectSettings`? Так Unity Hub сам создаст корректный проект для выбранной версии Unity и шаблона; сейчас ни версия, ни пайплайн не утверждены.
