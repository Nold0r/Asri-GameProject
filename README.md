# Игровой проект — рогалик / слэшер / экстракшен

Здесь находятся **реальная документация из вашего исходного архива** (сохранены утверждённые механики), Obsidian-хранилище, инструкции Claude Code, установщик полноценных сторонних навыков для лора и сюжета, а также место под будущую Unity-игру.

## С чего начать

1. Распакуйте архив целиком, **сохраняя скрытые папки** `.obsidian` и `.claude`.
2. В Obsidian выберите «Open folder as vault» и укажите именно `GameProject/design-doc`, **не** корень `GameProject`.
3. Откройте `00 — Главная.md`.
4. **Один раз запустите `УСТАНОВИТЬ_НАВЫКИ.cmd` (нужны Python 3 и интернет)**. Он скачает оригинальные скиллы из пяти указанных источников и поместит их только в каталоги лора/сюжета. Без запуска установщика сторонние скиллы ещё не установлены.
5. Для Claude Code откройте терминал в корне `GameProject`, выполните `claude`, либо начните с папки `design-doc/02. Мир и лор`, если работаете только над миром.
6. Настройки медиа уже указаны в `.obsidian/app.json`: всё новое, вставляемое в заметки, складывается в `Медиа/Вложения/`.
7. Когда придёт время создавать игру, создайте Unity-проект через Unity Hub **в новой** папке `GameProject/UnityProject/Game` — она намеренно отсутствует, чтобы Unity Hub не пытался использовать непустой проект.

## Важно

- Существующие согласованные правила перенесены из `design-doc.zip` с обновлением внутренних ссылок. Оригинальный ZIP сохранён в `Backups/`.
- Творческие документы на русском; Unity/C# и технические имена файлов кода — на английском.
- В этой версии **удалены три самодельных SKILL.md**. Вместо них приложен установщик, который получает оригинальные сторонние навыки (5 источников, включая полный `skills/` Story Skills). В самом ZIP исходники этих сторонних навыков не встроены из-за ограничений среды скачивания; после установки они сохраняются локально и не требуют интернета для обычной работы.
- После установки навыки лора будут находиться в `design-doc/02. Мир и лор/.claude/skills/`, а навыки сюжета — в `design-doc/04. Сюжет и повествование/.claude/skills/`. Они загружаются при работе в соответствующих ветках (см. `КАК_ПОЛЬЗОВАТЬСЯ_С_CLAUDE.md`).
- Не путайте авторский канон и гипотезы агента: любые новые предложения идут в черновики до утверждения.

Документация: [[00 — Главная]] (ссылка открывается внутри Obsidian) или `design-doc/00 — Главная.md` в файловом менеджере.
